LEADY COMMERCE — VERSION PROPRE

1. Mets tous les fichiers dans le même dossier.
2. Ajoute logo-leady.jpg.
3. Ouvre supabase-config.js.
4. Mets l'URL de TON projet Supabase et la clé ANON/PUBLIQUE.
5. Dans Supabase Authentication > Users, crée réellement le compte administrateur avec l'email voulu et son mot de passe.
6. Le nom de table par défaut est "chevaux".
7. La table doit autoriser la lecture publique si tu veux afficher les chevaux sans connexion.
8. Pour la gestion, les règles RLS doivent autoriser l'utilisateur connecté à insérer/supprimer les chevaux.
9. Ne mets JAMAIS une clé service_role dans le navigateur.

IMPORTANT :
Ce ZIP ne peut pas inventer l'URL Supabase ni la clé ANON de ton projet. Tant que ces deux valeurs ne sont pas remplacées, la connexion affichera clairement "Supabase non configuré".
Le mot de passe n'est volontairement pas enregistré dans les fichiers du site.
